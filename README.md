- 核验涵盖远端文件/提交一致性、可见性、来源历史、文档链接和内容筛查。报告中的历史实验结果不因归档而成为重新运行的结论。
- Git 副本不自动包含 GitHub 问题、PR 讨论、运行日志、外部数据或提交平台上的附件；正式提交附件需要另外保存来源和校验值。
- 本地独立 Git bundle 备份已通过校验和独立恢复检查。备份恢复后仍需另行恢复外部数据。
