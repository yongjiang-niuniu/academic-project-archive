## 提交、核验与保留范围

- [COMMITS.md](COMMITS.md) 记录本次实际新增的归档和说明提交；原开发历史保留原作者与日期。
- [repositories.json](repositories.json) 记录仓库地址、已保存版本和来源分支。目录自身的提交可在 GitHub 的提交历史中查看。
- 本次检查涵盖远端文件/提交一致性、可见性、来源历史、文档链接及归档内容筛查。代码运行结果与论文结果不因归档而成为重新验证的实验结论。
- Git 仓库保留的是 Git 管理的内容。GitHub 问题、PR 讨论、运行日志、外部数据和提交平台上的附件不自动包含在 Git 副本中。
- 本地另行生成独立 Git bundle 备份和 SHA-256 清单；备份恢复后仍需另行恢复外部数据。
